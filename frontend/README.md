# Surplus-to-Shelter Frontend

Modern Next.js 14 + Tailwind CSS application for food rescue dispatch and tracking.

## Routes

- **`/`**: Home landing page with links to all portals.
- **`/donate`**: Mobile-friendly surplus posting form with food description, quantity, 1-12 hour slider, address, and big green "Post Surplus" button.
- **`/dashboard`**: Dark-themed live impact telemetry with 4 stat cards (Meals Rescued, Kg Saved, CO2 Avoided, Active Matches) and recent matches list.
- **`/driver`**: Mobile-friendly driver portal with cargo manifest and the 3 big action buttons: "Accept Job", "Picked Up", and "Delivered".
